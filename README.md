# TourAssistant

TourAssistant is a travel assistant that helps visitors plan trips and discover attractions in Tanzania.

## About

This project includes a website and a backend for providing information related to travel in Tanzania.

## Main files

- `safarismart-tz.html` — the website page
- `safarismart_backend.py` — the application backend

## Getting started

Open `safarismart-tz.html` in a web browser to view the website..

## Security

Do not upload files containing passwords or API keys, such as `safarismart_backend.env`.
